🔑 ตั้งค่า YouTube API Key

เว็บนี้ใช้ YouTube Data API v3 ในการค้นหาและเล่นวิดีโอ ต้องใช้ API Key ฟรีจาก Google

  1. เปิด YouTube Data API v3 → กด Enable
  2. ไปที่ Credentials → Create Credentials → API Key
  3. คัดลอก Key มาใส่ช่องด้านล่าง

🔒 Key เก็บในเครื่องคุณเท่านั้น (localStorage)
